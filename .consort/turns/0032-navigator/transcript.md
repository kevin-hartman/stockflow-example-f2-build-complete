## Final reasoning

All 16 RED tests for S2 are written, but I haven't run any of them. The only check I ran was the response-formatter self-check, which passed.

- **Backend (T36–T39):** `tests/test_stock_listing_index.py`. The SC5 migration doesn't exist yet. The migration tests find it by searching `alembic/versions/` for `ix_stock_records_location_sku_held` and take its `down_revision`.
- **StockTable component (T40–T42, T46, T47, T49, T50):** `client/tests/components/StockTable.test.tsx`, which imports `StockTable` from `client/src/components/StockTable`. It doesn't exist yet. I assumed the component takes a `rows` prop holding what `GET /api/stock` returns.
- **Playwright specs:** `stock-by-location-table.spec.ts` (T43–T45), `stock-quantity-alignment.spec.ts` (T48) and `stock-empty-location.spec.ts` (T51), all under `client/tests/e2e/`.

I picked three test ids that the Driver's markup has to match: `tracking-not-tracked`, `warehouse-select` and `stock-table`.

T39 compares host, port and database against `DATABASE_URL`, not the whole URL string. The app rewrites the URL (driver, sslmode, application_name), so a full-string match would fail on a correct setup. It will also fail if `DATABASE_URL` isn't set in the environment, since the test reads it directly.
