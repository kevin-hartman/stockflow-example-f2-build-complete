- **T62 and T65** fail: they expect the service's validation errors to carry a `field` attribute ("delta" / "quantity"), which the service doesn't set yet. The test calls the service with a `MagicMock` session and a patched repository, and asserts that the write path is never called.

My `_fields()` helper also accepts pydantic's `loc` list as "naming the field", so the assertion on the `quantity` field passes without the AC's `{field, message}` shape. These four are born-green regression guards, not RED.

Everything runs without any teardown. Each test seeds a per-run-unique `(sku, location)` pair at quantity 7 and checks only its own rows.
